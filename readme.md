# 🇵🇱 Program Żużlowy (Speedway Live Score & Program)

Aplikacja internetowa typu PWA (Progressive Web App) do śledzenia, prowadzenia i analizowania programu meczu żużlowego na żywo.

## 🚀 Funkcje

- **Program Meczowy:** Śledzenie biegów, obsługa punktacji zawodników i kartotek zespołów.
- **Wsparcie PWA:** Możliwość instalacji aplikacji na telefonie lub komputerze (działa również w trybie offline).
- **Automatyczne przeliczanie:** Kalkulacja punktów zdobytych przez zawodników oraz sumarycznego wyniku meczu.
- **Responsywny Interfejs:** Dostosowany do urządzeń mobilnych oraz ekranów desktopowych.

## 🛠️ Technologie

- HTML5 / CSS3 / JavaScript (ES6+)
- Service Worker & Web App Manifest (PWA)

## 📱 Instalacja (PWA)

1. Otwórz aplikację w przeglądarce (np. Chrome, Safari, Edge).
2. Kliknij przycisk **"Zainstaluj"** w pasku adresu lub wybierz opcję **"Dodaj do ekranu głównego"** w menu przeglądarki.
3. Aplikacja pojawi się na liście Twoich aplikacji na urządzeniu.

## 💻 Uruchomienie lokalne

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/twoj-username/program-zuzlowy.git
   ```
2. Otwórz plik `index.html` w dowolnej przeglądarce internetowej lub użyj lokalnego serwera (np. Live Server w VS Code).

# 🇬🇧 Speedway Live Score & Program App

A Progressive Web App (PWA) for managing, tracking, and scoring speedway matches live.

## 🚀 Features

- **Match Heat Chart:** Live tracking of heats, rider points, and team scores.
- **PWA Support:** Installable on mobile and desktop devices with offline support.
- **Automatic Calculations:** Real-time computation of individual rider statistics and total team scores.
- **Responsive UI:** Clean and responsive user interface optimized for phones, tablets, and desktops.

## 🛠️ Tech Stack

- HTML5 / CSS3 / JavaScript (ES6+)
- Service Worker & Web App Manifest (PWA)

## 📱 Installation (PWA)

1. Open the application in your web browser (Chrome, Safari, Edge, etc.).
2. Click the **"Install"** button in the address bar or select **"Add to Home Screen"** from the browser menu.
3. Launch the app directly from your home screen or application list.

## 💻 Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/speedway-program.git
   ```
2. Open `index.html` in your web browser or use a local HTTP server (e.g., Live Server extension for VS Code).
